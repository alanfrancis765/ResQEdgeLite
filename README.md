

\# ResQ-Edge Lite



An offline, peer-to-peer disaster-response and SOS relay application.



\## Project goals



\- Capture structured emergency SOS reports.

\- Transfer SOS packets between Android phones without internet.

\- Relay packets through intermediate phones.

\- Suppress duplicate packets and enforce a hop limit.

\- Rank and cluster emergency reports on a responder dashboard.



\## Technology stack



\- Kotlin and Jetpack Compose

\- Google Nearby Connections

\- CBOR packet encoding

\- Room / SQLite

\- Offline map support
